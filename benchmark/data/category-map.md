## 조사표(2026-07-26) 세부 분류 49종 → 버킷

스펙 §4.1은 "조사표의 오류 분류를 그대로" 쓰라고 했으나, 실제 조사표는 49종 세부
분류였다. 그대로 쓰면 같은 현상이 쪼개져('명사구'와 '조사 띄어쓰기'가 모두 띄어쓰기)
어떤 시스템의 예측도 카테고리 일치가 불가능하므로, 채점 가능한 버킷으로 접는다
(**의도적 편차** — round-2 계획 시 스펙 정오표에 반영). 원본 세부 분류는 각 항목
rationale의 `[분류]` 태그로 보존되며, 매핑의 단일 소스는
`benchmark/export_audit.py`의 `CATEGORY_BUCKETS`다.

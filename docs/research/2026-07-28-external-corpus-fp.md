## 측정이 직접 이끈 수정 2건 (이번 브랜치에 반영됨)

1. **단어 중간 이/MM 아티팩트** — Kiwi가 미등록 외래어를 오분해하며 단어 중간에
   가짜 관형사를 만든다 (`메모이제이션` → `메모+이제+이/MM+션/NNP` → 지시어 '이션').
   지시 관형사는 단어 경계에서만 시작하도록 게이트 추가.
   효과: fe-news 466→461(−5), react 1,792→1,709(−83). 시드 벤치 F1 0.750 불변.
   Kiwi 분해는 문맥 의존이라 같은 단어도 주변 어절에 따라 오분해 여부가 달라진다
   (회귀 테스트에 최소 재현 문장 고정).
2. **lint 루트 부재 시 조용한 클린 종료** — 존재하지 않는 경로를 주면 `rglob`이 빈
   결과를 내 exit 0 "무진단 통과"로 위장됐다 (측정 중 경로 실수로 발견). exit 2로 수정.

## 무작위 표본 판정 (n=20, seed 42 — 예비, 단일 판정자)

fe-news 8건 + react 12건을 무작위 추출해 판정한 결과 **20건 전부 실질 오탐**
(독자가 해석에 실패할 참조 없음). "작성자가 고쳐야 할 진짜 모호"는 0건. 유형:

| 유형 | 예 | 설명 |
|---|---|---|
| (a) 구조 참조 | fe-news '이 글'·'이 데모'·'이 영상' (8건 중 7), react '위 예시'·'이 문서' | 선행사가 프로즈 명사구가 아니라 **링크된 콘텐츠·코드블록·문서 자체**. 현재 후보 우주(문장 윈도의 명사구) 밖에 있어 구조적으로 발화 |
| (b) 담화 지시 | react '이 원칙'·'이 변화'·'그 내용' | 선행사가 **명제/상황** — NP 상호참조 모델의 고전적 경계 밖 |
| (c) 자명한 1위 | react '이 툴팁' (후보 1위 '툴팁' 0.82) | 사람에겐 명백한 선행사가 1위인데 2위와 점수차 < threshold라 발화 — head_match 가중 부족/threshold 과대 신호 |

## threshold 민감도 (이번 브랜치의 config 연결로 측정)

| threshold | react | fe-news |
|---|---|---|
| 0.2 (기본) | 1,709 | 461 |
| 0.1 | 1,121 | 345 |
| 0.05 | 944 | 295 |

threshold만으로 react −44.8% · fe-news −36.0% 감축되지만 구조 참조·담화 지시
클래스는 잔존한다 — 점수 조정이 아니라 규칙적 처리(후보 우주 확장 또는 억제)가
필요한 클래스.

## TERM101 프로브 (표기 혼용, 소형 사전 1엔트리)

`애플리케이션[어플리케이션]` 사전으로 fe-news를 검사: **TERM101 2건 — grep 전수 실측
(어플리케이션 등장 2파일)과 정확히 일치, 파일·줄 번호 정확, 오탐 0.**
react ko는 어플리케이션 0 / 애플리케이션 61파일로 완전 통일 — 전문 번역 코퍼스는
용어집으로 표기를 강제한다는 대조군 데이터.

## Round-2 시사점 (표본 근거 우선순위)

1. **구조 참조 처리** — 코드블록·링크·제목을 후보 우주에 넣거나, (위|이)+구조 head
   (글/문서/예시/코드/데모/영상/세션)를 별도 규칙으로 억제. 표본 기준 최대 지렛대.
2. **head_match 가중·threshold 튜닝** — 조사표 벤치 위에서 config 스윕
   (`TtoryeotEngine(config)` + `run_engine`, CLI는 `lint --config`).
3. **담화 지시 head 분류** — 문제/경우/방법/원칙/변화 등 명제 선행사 head는 REF101
   범위 밖으로 (또는 별도 규칙으로 분리).
4. **인라인 코드 마스킹**(스펙 §5 미구현 항목) — `` `Array.prototype.at` 이 사용
   가능하다``처럼 코드 스팬 뒤 분리 표기된 조사가 관형사로 오분석되는 사례 실측됨.
5. **Kiwi 사용자 사전** — 도메인 외래어 등록으로 잔존 오분해 감소.
   (단어 경계 게이트는 실측 근거가 있었던 관형사(이/그) 경로에만 적용했다 —
   fused(해당/위)·attributive(동일한) 경로 미적용은 의도된 비대칭이며, 해당
   경로에서 아티팩트가 실측되면 같은 게이트를 확장한다.)

## 재현

```bash
git clone --depth 1 https://github.com/naver/fe-news corpus/external/fe-news
git clone --depth 1 --filter=blob:none --sparse https://github.com/reactjs/ko.react.dev \
  corpus/external/ko.react.dev
git -C corpus/external/ko.react.dev sparse-checkout set src/content

uv run ttoryeot lint corpus/external/fe-news                        # REF101만
uv run ttoryeot lint corpus/external/ko.react.dev/src/content
# 분포 집계는 반드시 Python Counter로 (macOS sort|uniq 한글 협착 함정)
```
